## Уникальные фичи (наши "фишки")

### Что делает NurChat особенным:

1. **Полная локальность** — SQLite + локальные файлы, никаких облаков
2. **Анонимность** — без номера/email, только username
3. **Гибрид P2P** — HTTP fallback + DataChannel для прямой передачи
4. **IPFS** — распределённое хранение файлов (уникально для мессенджеров)
5. **Встроенные стикерпаки** — кастомные пакеты без маркетплейса
6. **Секретные чаты с TTL** — исчезающие сообщения с таймером
7. **Книга закладок** — серверные закладки на сообщения
8. **Статистика** — графики активности, топ контактов
9. **P2P-звонки** — WebRTC напрямую без сервера
10. **Нативный Tauri** — легче Electron в 3-5 раз

## Ресурсы для реализации

- **MLS (Messaging Layer Security)** — IETF протокол для группового E2E: https://messaginglayersecurity.rocks/
- **WebRTC SFU** — Mediasoup / Janus для групповых звонков
- **Tor** — stem + onion routing для анонимности
- **Whisper API** — OpenAI для субтитров голосовых
- **react-window** — виртуализация длинных списков
