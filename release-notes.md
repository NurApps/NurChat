# NurChat — заметки к релизу

Десктопный мессенджер со сквозным шифрованием (Tauri + FastAPI relay).

## Установка

1. Скачайте `NurChat_*_x64-setup.exe` и установите.
2. При первом запуске укажите relay-сервер (host + протокол) или используйте адрес из приглашения друга.
3. Зарегистрируйте аккаунт — он живёт на выбранном relay.

## Что зашифровано

Текст, файлы, голосовые, подписи звонков — всё шифруется на устройстве (X3DH + Double Ratchet). Relay хранит только шифротекст и не может прочитать содержимое.

Полная честная картина — `docs/E2E_AND_TRANSPORT.md`.
Тест с друзьями через туннель — `docs/TUNNEL_FRIENDS.md`.
