# TESTING.md — предрелизный прогон вдвоём (разные сети)

Цель: два человека за разными роутерами переписываются, звонят, кидают
файлы через один релей. Фиксируем всё, что сломалось.

## Подготовка: Tailscale вместо туннелей (10 минут, $0, навсегда)

Туннели Cloudflare для вечера сойдут, но URL плавает и есть лимиты.
Правильный $0-путь без шаманства — **Tailscale**: приватная сеть поверх
интернета, белые адреса внутри, проброс портов не нужен, адрес вечный.

1. Ты и друг ставите Tailscale с [tailscale.com/download](https://tailscale.com/download)
   (Windows — next-next-finish), входите в ОДИН аккаунт (или шарите ноду
   друг другу — free-тариф, до 100 устройств).
2. У тебя: `tailscale ip` → запомни адрес вида `100.x.y.z`.
   Проверка связности у друга: `ping 100.x.y.z` — отвечает? Едем дальше.
3. У тебя релей слушает все интерфейсы:

```powershell
.venv\Scripts\python -m uvicorn server.main:app --host 0.0.0.0 --port 8000
```

4. Друг в приложении вводит **один раз**: хост `100.x.y.z:8000`,
   protocol `http`. Больше ничего — адрес не меняется никогда,
   туннели/перевводы не нужны, трафик шифрован самим WireGuard.

Запасной вариант (если Tailscale не встал): quick tunnel
`cloudflared tunnel --url http://localhost:8000` + ручной ввод
`xxx.trycloudflare.com` с protocol `https` (адрес живёт до рестарта).

Сборка установщика для друга (обязательно — NurChat только десктоп):

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY = Get-Content update_key_private.key -Raw
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = ""
npx tauri build
# exe: src-tauri\target\release\bundle\nsis\NurChat_*_x64-setup.exe
```

(Без ключа сборка упадёт — так задумано, ключ лежит в корне, в git не коммитится.
Другу также понадобится WebView2 — на Win10/11 обычно уже стоит, установщик
доставит сам.)

Отправь другу exe + адрес релея: либо `100.x.y.z:8000` с protocol `http`
(Tailscale), либо `xxx.trycloudflare.com` с protocol `https` (туннель, БЕЗ `https://`).

## Подключение друга

1. Установить, запустить. Увидит «Relay unavailable» — это нормально.
2. Ввести хост и protocol → приложение перезагрузится и зайдёт на форму входа.
   Ввод один раз — адрес запоминается навсегда.
3. Зарегистрироваться (капча — обычная арифметика). Ты — тоже, если ещё нет.

## Чеклист (по порядку, галочки)

### Связь
- [ ] Друг пишет тебе в личку (создай чат через «+» → по username)
- [ ] Ты отвечаешь, сообщения доходят обеим сторонам без перезагрузки
- [ ] Индикатор набора текста виден
- [ ] Статусы online/offline обновляются (выйди/зайди)

### Шифрование (важно!)
- [ ] Открой профиль собеседника → Safety Number с обеих сторон
      **ЦИФРЫ ДОЛЖНЫ СОВПАСТЬ**. Продиктуйте друг другу вслух.
      Не совпали = MITM/баг, дальше не тестим, пишем баг.
- [ ] Перезапусти оба приложения → история расшифровывается (сессии пережили рестарт)

### Сообщения
- [ ] Ответ (reply), реакция, редактирование, удаление у себя
- [ ] Удаление «у всех» — пропало у обоих?
- [ ] Эфемерное сообщение (таймер) — исчезло само?

### Файлы и голос
- [ ] Фото (jpg/png), документ (pdf/txt), голосовое сообщение
- [ ] Всё открывается и скачивается у получателя

### Группа
- [ ] Создай группу, добавь друга
- [ ] Переписка в группе с обеих сторон читается
- [ ] Удали друга из группы → он больше не читает новые сообщения

### Звонки (честно: без TURN может не взлететь)
- [ ] Аудиозвонок туда-обратно, слышно обе стороны?
- [ ] Видеозвонок, картинка идёт?
- [ ] Если звонок не соединяется (бесконечный «вызов») — запиши:
      оба за NAT? мобильный интернет у кого-то? Это ожидаемо без TURN.

### Контакты и безопасность
- [ ] Заявка в контакты → принять/отклонить
- [ ] Блокировка пользователя
- [ ] Включи 2FA у себя (Настройки → Безопасность): QR → код → backup-коды
      сохрани! Разлогинься → войди с кодом 2FA
- [ ] PIN-блокировка приложения

### Стресс (если не лень)
- [ ] Один уходит в офлайн (закрыть app), второй шлёт 5 сообщений →
      первый заходит, всё доставлено?
- [ ] Быстрая серия из 10 сообщений подряд — порядок и доставка ок?

## Как фиксировать баги

Для каждого бага запиши:
1. Что делали (шаги), что ожидали, что получили
2. Версия приложения (Настройки → О программе) у обоих
3. Время бага → потом смотрим серверный лог (`logs/nurchat.log`) за это время
4. Скрин/запись экрана, если визуальное

Серверные логи: `logs/nurchat.log`, `logs/websocket.log`.
Клиентские: DevTools в Tauri нет — смотри поведение + серверный лог.

## Заранее известные ограничения (не баги)

- Звонки без TURN-сервера за строгим NAT могут не соединиться
- Метаданные (кто/когда) релей видит — так задумано, контент зашифрован
- Первая страница истории грузит последние 50 сообщений
