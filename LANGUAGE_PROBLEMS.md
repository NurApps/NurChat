# Проблемы локализации

Дата аудита: 2026-09-19
Файлы переводов: `frontend/src/i18n/locales/en.json`, `frontend/src/i18n/locales/ru.json` (по 532 ключа, полностью синхронизированы).

## Сильные стороны (для контекста)

- `en.json` и `ru.json` содержат идентичный набор ключей — 0 пропусков в обе стороны.
- Все `{{interpolation}}`-переменные (`{{count}}`, `{{total}}` и т.д.) совпадают между языками.
- Пустых строк нет; идентичных en=ru значений всего 3, и все легитимны (`common.appName`, `auth.usernamePlaceholder`, `settings.pinPlaceholder`).
- Даты форматируются через `toLocaleDateString(i18n.language, ...)` в `frontend/src/utils/format.ts` — корректно привязаны к текущему языку.
- Настроена автодетекция языка (`i18next-browser-languagedetector`: localStorage → navigator), fallback на `ru`.

## Найденные проблемы

### 1. Нет переключателя языка в UI
Ключ `settings.language` ("Язык" / "Language") существует в обоих файлах перевода, но не используется ни в одном компоненте (`grep` по `src` не находит обращений к нему). Пользователь не может сменить язык вручную из интерфейса — только через настройки браузера или прямую правку `localStorage.i18nextLng`.

### 2. Захардкоженные русские строки (не через `t()`)
Эти строки всегда отображаются на русском, даже если выбран английский язык:

| Файл | Строка/строки |
|---|---|
| `frontend/src/pages/ProfilePage.tsx` | `"Профиль"`, `"Имя"`, `"Фамилия"`, `"Статус"`, `"О себе"`, `"Дата регистрации"` |
| `frontend/src/pages/CallHistoryPage.tsx` | `"История звонков"`, `"Загрузка..."`, `"Нет звонков"` |
| `frontend/src/pages/MobileChatPage.tsx` | `"Выберите чат"`, `"Начните общение, выбрав чат из списка"` |
| `frontend/src/components/CreateChatModal.tsx` | `"Секретный чат"`, `"Сообщения исчезают через:"` |
| `frontend/src/App.tsx` | `"Перейти к основному содержимому"` (skip-link) |
| `frontend/src/components/SafetyNumberModal.tsx` | `"Закрыть"` |
| `frontend/src/pages/ChatPage.tsx:818` | символ закрытия сериализован как `"Г—"` (кракозябра вместо `×`, вероятно проблема кодировки при сохранении файла) |

Итого 17 мест.

### 3. Отсутствует поддержка множественного числа (плюрализация)
В обоих файлах переводов 0 ключей с суффиксами `_one/_few/_many/_other` — плюрализация i18next не используется вообще. Для русского языка это приводит к грамматически неверным формам при счётчиках:

- `settings.filesCount`: `"{{count}} файлов"` — неверно для 1 ("1 файлов" вместо "1 файл"), 2–4 ("2 файлов" вместо "2 файла").
- `settings.members`: `"Участники ({{count}})"` — аналогичная проблема с "участников/участника/участник" при желании писать текстом, сейчас скрыта скобками, но при других формулировках проявится.

Для времени (`minutesAgo`, `hoursAgo`, `daysAgo`) проблему обошли, используя несклоняемые сокращения ("мин назад", "ч назад", "дн назад") — этот приём сработал, но не применён везде, где есть счётчики.

## Рекомендации (не выполнено, только на будущее)

1. Добавить переключатель языка в `SettingsPage` — ключ `settings.language` уже готов, нужно подключить `i18n.changeLanguage()`.
2. Вынести 17 хардкодов через `t()` в соответствующие JSON-файлы.
3. Исправить кракозябру `"Г—"` в `ChatPage.tsx:818` на `×` (или `&times;`/юникод-escape).
4. Добавить плюрализацию через стандартный механизм i18next (`_one`/`_few`/`_many`/`_other`) минимум для `filesCount` и `members`.
